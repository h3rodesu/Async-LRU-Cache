# Asynchronous LRU Cache

Асинхронный LRU-кэш на C++20 с сохранением вытесненных элементов в PostgreSQL. Проект демонстрирует реализацию классического алгоритма вытеснения Least Recently Used с фоновой записью в базу данных через отдельный поток.

**P.S.** Графический интерфейс отсутствует — только консольное меню.

## Технологический стек

* Язык программирования: C++20
* Многопоточность: `std::thread`, `std::mutex`, `std::condition_variable`
* Система сборки: CMake, MSBuild (Visual Studio)
* Библиотека libpqxx https://github.com/jtv/libpqxx
* Менеджер пакетов: vcpkg
* База данных: PostgreSQL

## Структура проекта

* main.cpp - точка входа в приложение, консольный интерфейс и вспомогательный класс `HeavyData`.
* NewCache.h - объявление шаблонного класса `Cache<K, V>`, содержащего `std::list` для порядка использования (перемещение и удаление за О(1)), и `std::unordered_map` для поиска за О(1).
* Cache.ipp - реализация методов кэша, включается из `NewCache.h`.
* CMakeLists.txt - сценарий сборки.

## Возможности

* LRU-вытеснение за O(1) - поиск, вставка и удаление через `std::list` + `std::unordered_map`
* Асинхронная запись в БД - отдельный поток не блокирует основную работу
* Потокобезопасность - раздельные мьютексы для кэша и для очереди в БД
* Шаблонный класс - поддерживает произвольные типы значений, включая move-only (например, `std::unique_ptr`)
* Валидация ввода - устойчивость к буквам вместо чисел и отрицательным значениям
* Обработка ошибок - поимка исключений, программа не падает

## Сборка и запуск

### Требования к окружению

* Компилятор с поддержкой стандарта C++20 или выше
* CMake версии 3.20 или выше
* Установленный менеджер пакетов vcpkg (проект использует манифест vcpkg.json)
* Запущенный PostgreSQL 12+

### Сборка через консоль (CMake)

Выполните следующие команды в терминале из корневой папки проекта:

```bash
mkdir build
cd build
cmake .. -DCMAKE_TOOLCHAIN_FILE=[путь_до_vcpkg]/scripts/buildsystems/vcpkg.cmake -DVCPKG_TARGET_TRIPLET=x64-windows
cmake --build . --config Release
```

> **Важно:** путь до vcpkg указывается через прямые слеши (`C:/vcpkg/...`). Без `-DCMAKE_TOOLCHAIN_FILE` CMake не найдёт `libpqxx`.

### Сборка через Visual Studio

1. Откройте папку проекта через **`File -> Open -> Folder`**
2. Visual Studio подтянет `CMakeLists.txt` автоматически
3. Дождитесь окончания конфигурации CMake (окно `Output -> CMake`)
4. `Build -> Build All` (`Ctrl+Shift+B`)

### Настройка базы данных

Перед первым запуском создайте базу данных:

```sql
CREATE DATABASE "New_Cache";
```
